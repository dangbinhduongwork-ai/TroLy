📁 Workspace
🤖
Xin chào! Tôi là Trợ Lý AI trên Windows. Tôi có thể giúp bạn:
  • 📁 Quản lý file & thư mục: tạo, đọc, sửa, sắp xếp thông minh.
  • 📄 Tài liệu văn phòng: đọc/tạo PDF, Word (.docx), Excel (.xlsx).
  • 🌐 Tra cứu web: tổng hợp thông tin với chế độ bảo mật chống SSRF.
  • ⏰ Nhắc việc đúng giờ: báo thức, hoãn nhắc và phát thông báo Windows Toast.
  • 🧠 Ghi nhớ dữ kiện: sở thích, quy tắc đặt tên, dự án của bạn qua các phiên.
Hãy nhập câu hỏi hoặc yêu cầu bằng tiếng Việt bên dưới để bắt đầu!
